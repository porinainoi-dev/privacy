👑 Политика конфиденциальности

Приложение «Нарциссический круто»
Дата вступления в силу: 03.09.2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные собирает и обрабатывает приложение «Нарциссический круто» (далее — «Приложение»), разработанное и опубликованное в RuStore.

Установка и использование Приложения означает, что Вы ознакомились с настоящей политикой и согласны с её условиями.

2. Какие данные собирает Приложение

2.1. Данные, которые мы НЕ собираем

Приложение не собирает, не передаёт и не хранит на серверах разработчика какие-либо персональные данные пользователей. Мы не запрашиваем и не обрабатываем:

  • Имя, фамилию, телефон, email пользователя
  • Геолокацию
  • Контакты из телефонной книги
  • Данные банковских карт
  • Историю звонков и сообщений

2.2. Данные, которые хранятся локально на устройстве

Все данные, создаваемые пользователем в Приложении (аватарка, список заданий, игровой прогресс, очки, уровень, статусы), сохраняются исключительно в локальном хранилище устройства и никуда не передаются. При удалении Приложения эти данные удаляются без возможности восстановления.

2.3. Разрешения, запрашиваемые Приложением

Приложение может запрашивать следующие разрешения:

  • CAMERA (камера) — для создания фото аватара. Изображение сохраняется только локально на устройстве.
  • READ_EXTERNAL_STORAGE / READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO — для выбора и открытия файлов: фото для аватара, музыка для плеера, видео для просмотра, текстовые файлы для чтения.
  • WRITE_EXTERNAL_STORAGE — для сохранения фото аватара локально на устройстве.

Все данные, полученные с помощью этих разрешений, остаются на устройстве пользователя и никуда не передаются.

3. Передача данных третьим лицам

Мы не передаём, не продаём и не раскрываем персональные данные пользователей третьим лицам.

Приложение не использует сторонние аналитические SDK (такие как Firebase, AppMetrica, Google Analytics и другие), не собирает статистику использования и не отправляет данные на внешние серверы.

4. Хранение и защита данных

Все данные хранятся только на устройстве пользователя. Разработчик не имеет доступа к этим данным и не несёт ответственности за их сохранность на устройстве. Безопасность данных на устройстве обеспечивается стандартными механизмами операционной системы Android.
